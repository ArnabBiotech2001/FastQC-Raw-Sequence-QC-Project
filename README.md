# FastQC-Based Quality Control Analysis

A bioinformatics project focused on assessing the quality of raw sequencing data using **FastQC** and **MultiQC**.

### Dataset

* **Accession:** ERR17427481
* **Data:** Raw FASTQ sequencing data

### Tools

* FastQC
* MultiQC
* SRA Toolkit
* Linux/WSL

### Workflow

**Raw FASTQ → FastQC → MultiQC → Quality Assessment → Trimming (if required) → Final QC**

**Status:** In Progress
